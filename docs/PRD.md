# 咸鱼小市场 · 产品需求文档（PRD）

> 一句话：**让孩子手里的闲置「游」起来** —— 同班/同小区的孩子以物换物，
> 家长微信双确认，AI 一键估值，用「咸鱼币」攒荣誉。
>
> 版本 v0.1（比赛演示版） · 技术栈 FastAPI + 微信小程序

---

## 1. 背景与真实痛点

1. **孩子手上有大量闲置**：奥特曼卡、读过的绘本、玩腻的玩具、义卖剩的文具堆满抽屉。
2. **孩子天生爱交换**：校园里私下交换卡牌的热度是真实存在的，只是没有安全、被家长认可的方式。
3. **家长/学校的顾虑**：
   - 💸 小学生没有独立支付能力，任何「买卖」都绕不开家长代付；
   - ⚖️ 8 岁以上孩子是限制民事行为能力人，网络交易家长可主张无效，平台背退款风险；
   - 🚦 学校普遍禁止带卡牌等物品到校交易，一个鼓励「买卖」的 App 会站到学校对立面。

**→ 我们的解法：把「买卖」换成「交换」，把「平台」换成「工具」。**

---

## 2. 产品定位（方向 A，为主轴）

| 是什么 | 不是什么 |
|---|---|
| 同班/同小区孩子**以物换物**的工具 | ❌ 线上买卖 / 二手电商 |
| AI 估值 + 咸鱼币**积分激励** | ❌ 任何形式的金钱结算 |
| 家长双确认 + 线下当面交换 | ❌ 平台介入物流 |
| 循环经济 + 财商启蒙 | ❌ 纯给孩子做作业 |

**一句话价值主张**：让孩子闲置换闲置，锻炼定价、谈判与分享；给家长和学校一张「不涉及钱、可追溯、可停下」的安全网。

---

## 3. 咸鱼币：积分经济（合规红线）

咸鱼币 = **行为积分**，不是货币。三条铁律写死在代码注释与产品文案里：

1. ❌ **不可兑换现金** —— 任何页面、接口都不存在「余额→人民币」路径。
2. ❌ **不可转账/交易** —— 积分只由系统规则发放或收回，**没有用户间转移接口**。
3. ❌ **不可购买商品** —— 排行榜只提供荣誉（情绪价值）。

**获取规则（v1）**：

| 行为 | 增减 | 说明 |
|---|---|---|
| 注册 | +10 🐟 | 欢迎礼 |
| 上架一件闲置 | +2 🐟/件 | 让闲置「游」起来 |
| 完成一次交换 | +10 🐟/双方 | 绿色消费践行者 |
| 无故取消交换 | -2 🐟（发起方） | 守护契约精神，治理随意发起 |

**负面治理**：取消扣分、一物多换拦截、家长拒绝不计发起方责任（孩子不承担拒绝成本）。

**未来规划（路演可提，不承诺上线）**：
- 🏅 勋章系统：里程碑（首次交换、交换 5 次、环保达人）自动解锁；
- ✏️ 咸鸭站兑换：由学校/家委会运营，咸鱼币可兑换本子、笔、橡皮擦等小文具
  （属运营方单方赠品计划，与任何支付无关，需家长知情同意。**当前版本仅预留 `burn` 积分接口，未开放**）。

## 3. 核心流程（3 分钟路演脚本）

```
孩子拍下奥特曼卡
  → AI 识别「奥特曼卡 · 九成新 · 建议 3 咸鱼币」
  → 上架，鱼塘出现一张卡片
  → 同班同学逛到，选「用我的宝贝换这个」
  → 发起方家长微信收到订阅消息 → 确认
  → 接收方家长微信收到订阅消息 → 确认
  → 双方约定「课间当面交换」
  → 双方家长点「交换完成」，各 +10 🐟
  → 排行榜上「本月我最环保」
```

全程**零金钱流**、**每一步都有家长确认记录**、**线下交付**，把「交换」做成安全网的闭环。

## 4. 功能模块

### 4.1 鱼塘（首页）
- 同校/同班闲置浏览，按类别筛选（奥特曼卡/绘本/玩具/文具/体育用品…）。
- 搜索、AI 一键估值展示、想换标签。

### 4.2 上架（拍照 + 估值）
- 拍照（最多 3 张，真实上传到 `/uploads` 静态托管）→ 填名称/类别/新旧 → **AI 估值（咸鱼币）** → 可手动微调枚数 → 定「想换什么」→ 上架（+2 🐟）。
- 新旧档位：崭新 / 九成新 / 八成新 / 七成新 / 有磨损。
- AI 估值两级：**视觉大模型**（可选，读照片识别成色，返回枚数+置信度）→ 未配置 Key / 失败时**自动回退规则引擎**，保证演示不断。

### 4.3 交换（以物换物）
- 请求时选择「我能给的那件」+ 对方那件。
- 状态机：`待发起方确认 → 待接收方确认 → 双方确认(线下交换) → 完成`，任一方未确认可取消/拒绝。
- 完成时双方 +10 🐟，物品标记「已换出」。

### 4.4 咸鱼币 & 排行榜
- 我的余额、咸鱼币流水（可审计，每笔都有来源 ID）。
- 明星榜（前 3 领奖台 + 全榜），仅昵称/班级/头像，保护隐私。

### 4.5 家长端（微信订阅消息）
- 发起/收到交换 → 双方家长收到订阅消息确认。
- 演示模式将消息落库，在「家长通知」收件箱模拟展示（3 分钟路演够用）。

### 4.6 内容治理：举报 + 管理员审核（合规刚需）
- 任何登录用户可对某件闲置「举报」（固定理由 + 自由备注，同一人对同一物只能报一次）。
- 被举报物品**不下沉公示**（仍可见但带标记），交由管理员判断。
- 管理员（昵称/openid 在 `ADMIN_OPENIDS` 名单 → 登录时自动置为 `role=admin`）：后台查看待处理举报，可**下架**（物品 status→`removed`，不再展示）或**驳回**（认定无违规，物品保留）。
- 下架原因记录在物品上，供物主/家长知情；全程留痕（举报人、处理人、时间）。

### 4.7 组织（隔离边界，合规关键）
- **不靠定位**：全国用户不能混在一个鱼塘；内容按「组织」隔离（学校 / 小区 / 其他）。
- **创建**：用户申请创建组织 → **平台超管审核**（admin-web「组织审核」）→ 通过后生成邀请码，创建者成为组织管理员。
- **加入**：仅邀请码 / 链接；提交后 **组织管理员在小程序内审核**通过，方可成为正式成员。
- **切换**：一人可加入多个组织，选择当前组织后，鱼塘 / 上架 / 交换 / 排行只看该组织。
- **组织管理（小程序，非超管后台）**：邀请码管理、审成员、下架本组织闲置。
- **超管后台职责**：只审「创建组织」申请；不介入组织日常运营。

## 5. 技术架构

```
微信小程序 (WXML/WXSS/JS)
      │  wx.request / wx.uploadFile / wx.login
      ▼
FastAPI (Python)  ── SQLAlchemy ── SQLite
   │  app/routers   HTTP 接口（含 /upload 图片上传 + /uploads 静态托管）
   ├─ services/coin_service   咸鱼币积分 + 流水台账
   ├─ services/ai_pricing    视觉大模型估值（可配置）→ 规则引擎兜底
   ├─ services/swap_service   交换状态机
   ├─ services/org_service    组织审核 / 成员身份 / 邀请码
   ├─ services/wechat_service 订阅消息（mock / 真实）+ 微信登录 token
   └─ services/token         HMAC 签名令牌（真实登录）
```

### 数据模型核心
- `User`：openid（孩子）+ parent_openid（家长）+ 咸鱼币余额 + `active_org_id`
- `Organization`：名称 / 类型 / 平台审核状态 / 邀请码
- `OrgMembership`：成员角色（owner/admin/member）与加入状态（pending/active）
- `Item`：owner / **org_id** / 类别 / 新旧 / value_coins / want_tags / status
- `Swap`：发起物品 + 接受物品 + 状态 + 4 个家长确认位
- `CoinLedger`：咸鱼币流水（防重复发放的幂等唯一约束）

### 认证
- 演示：`code=昵称` 免登录（比赛用）。
- 真实：`wx.login → jscode2session → openid`，签 HMAC 签名令牌（标准库实现，格式同 JWT，7 天有效，可篡改校验）。

### AI 估值两级
- **视觉大模型**（已接入）：`AI_VISION_ENABLED=1` 并配 Key 后调用 OpenAI 兼容接口识别照片+成色 → 枚数+置信度；未配置/失败自动回退。
- **规则引擎兜底**：关键词 + 新旧折减系数，零成本离线可跑，保证演示和离线环境不断。

## 6. 合规与安全自查

| 风险 | 对策 |
|---|---|
| 未成年网络交易法律风险 | **全程零资金流**，纯以物换物，无任何买卖 |
| 退款/售后 | 无支付，无退款概念；交换由双方家长当面完成 |
| 纠纷 | 家长双确认 + 线下当面 + 完成需双方点；异常取消有记录 |
| 一物多换 | 换入物品锁定，防一物多换 |
| 隐私 | 展示昵称/班级，家长名不显示；排行榜不做隐私泄露 |
| 上线类目审核 | 比赛用测试号+DEMO_MODE；正式上线走教育类目资质，**PPT 不承诺已上线** |
| 校园规则 | 带上「互换」而非「交易」叙事，配套班主任/家委会共建话术 |
